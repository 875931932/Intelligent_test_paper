# 教学资料、共享知识库与课程命题的一体化

## 产品主线

PaperPact 面向教师：教学资料积累与授权共享支撑课程命题，课程命题仍是核心应用。学生身份、在线考试及阅卷不在本次范围内。

登录默认进入「资料与知识中心」。该入口包含「我的资料」和「校级共享库」，通过「课程命题」进入原有课程工作台。

```text
已有课程资料 / 新上传资料
    → 我的资料（跨本人课程汇总，不搬迁历史文件）
    → 显式选择共享库与范围确认
    → 待发布版本 → 解析预览 → 发布
    → 授权教师检索、问答、选用到课程
    → 原有资料解析、命题框架、知识目录、合同、试卷生产线
```

## 教师操作

1. 旧课程的资料直接显示在「我的资料」，可按课程和资料名查找。
2. 「发布到共享库」使用已存文件，无需重新上传。选择可编辑的库、确认分享权限后，先创建待发布版本。
3. 发布者检查解析正文后发布。共享范围决定可见教师，课程选用许可决定读者能否复制到课程。
4. 共享资料首次选用到其他课程时形成独立固定版本，资料卡保留来源库和版本，可跳回来源查看更新。
5. 原课程「上传新版」追加资料版本；再共享到同一库时追加同一文档的版本。新版本未发布前，旧发布版本继续服务。
6. 共享库新版由教师再次选用后，追加到目标课程的原资料。存在本地修改时返回冲突，不直接覆盖；本地修改后仍保留来源提示及转分享限制。
7. 从共享库选回自己的源课程时直接定位已有资料，重复选用相同版本不重复创建。若已删除此前导入的副本，重复导入原版本返回明确冲突，当前未实现回收站恢复。

资料中心的「上传资料」选择课程后复用课程上传界面。共享库的主操作是「从我的资料添加」；「上传新资料」保留给不属于具体课程的公共资料。文件上传共用前端客户端；课程文件共享与共享库直接上传共用知识版本入库服务，不要求教师重复上传同一文件。

## 数据与权限

| 概念 | 当前实现 |
| --- | --- |
| 我的资料 | 实时汇总本人拥有课程内的最新资料版本，不创建第二套私人文件记录 |
| 共享版本 | 独立文件快照，使用既有 `knowledge_document_versions.import_origin` 保存课程来源 |
| 课程选用 | 使用既有 `course_knowledge_imports` 记录授权回执和固定版本关系 |
| 重复共享 | 同课程资料、同库沿用文档；同源版本幂等 |
| 更新 | 显式追加版本，历史资料和已冻结命题引用保持不变 |
| 授权 | 课程 owner 校验 + 知识域现有 policies 判定；管理员不自动取得正文权限 |
| 保密 | 考核大纲拒绝共享；其他资料需声明不含保密内容；导入共享资料的整个版本链禁止重新分享扩大范围 |
| 来源展示 | 其他读者仅见共享来源标题和版本，不暴露私有课程 ID 或跳转链接 |
| 课程选用许可 | 新建库可显式勾选；负责人可在成员与权限页调整。撤销仅阻止后续选用 |

两个权限域仍保留独立快照，尚未合并为一张物理资源表。共享和课程选用复制原始文件，解析结果暂未跨域复用。共享入库沿用 Markdown、TXT、PDF、DOCX 支持范围，课程内其他格式继续保留并提示暂不能共享。本次没有表结构变更，也不需要为已有课程资料执行迁移。

新增接口：

- `GET /api/v1/knowledge/course-materials?course_id=...`
- `POST /api/v1/knowledge/spaces/{space_id}/import-from-course`

共享版本沿用既有 parse job、outbox 和 knowledge worker。未改动三个已封存的命题工作流。

## 验证与发布范围

桥接集成测试位于 `backend/tests/integration/test_knowledge_course_bridge.py`，覆盖旧资料可见、双边权限、显式确认、源版本追加、源删除后副本保留、课程副本追加、本地冲突、转分享限制、满库更新、存储故障及选回源课程幂等。

```powershell
cd backend
uv run pytest -q
cd ../frontend
npm run build
npm run lint
```

浏览器检查使用隔离 SQLite、本地文件存储和开发用进程内任务执行器，覆盖真实 HTTP 上传、共享、发布、课程选用、版本追加及桌面/手机布局。它不证明 Redis 消息传输、PostgreSQL 并发锁或线上容量；本次不调用真实模型、不执行生产数据库迁移，也不部署到线上服务器。

现有固定人工评测集、真实 PostgreSQL 容量/恢复演练及模型化知识问答的未完成事项不由本次资料整合替代。
