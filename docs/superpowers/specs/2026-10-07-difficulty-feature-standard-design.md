# 题目难度特征化标准 Design（Difficulty Feature Standard v1）

> 日期：2026-10-07　状态：v1 已实现　关联：作品方案第四章「测试优化·难度问卷」章节

## 1. 背景与问题

系统中难度此前的形态是**裸标签 + prompt 穿透**：

- 标签来源：考纲/教师只声明**占比**（`difficulty_distribution`），蓝图按最大余数法把
  `low/medium/high` 配额分配到题位——难度是**配额分配结果，不是内容测量**；
- 下发方式：`BatchQuestionSpec` 把 `difficulty` 枚举值原样放进 payload，出题 system
  prompt 里**没有任何三档难度的定义**——模型只收到一个无语义的字符串，按自身倾向"尽量贴"；
- 终检缺口：唯一的难度检查是"低档题干不得含高阶认知关键词"，且**只认 `low` 字面**
  ——前端表单与 AI 单题创建走的 `easy/hard` 词表完全绕过该检查；认知层次与难度的
  一致性无人校验。

实测佐证：后端真实生成的 41 题（大模型调优课程）全部标 `medium`，其中
"可复现评测报告必备的三部分是？"这类记忆级单步题也被标 `medium`——没有标准时，
medium 只是配额残余。这正合项目核心纪律：**确定性算法保证全局约束，模型只负责写题。**

## 2. 调研依据：教学资料如何定义题目难度

三类定义角度，各有适用环节：

| 类别 | 代表 | 要点 | 在本设计中的角色 |
|---|---|---|---|
| **实证角度**（事后测得） | CTT 难度系数 P 值（客观题答对率/主观题得分率）、IRT 难度参数 b | 客观但需要实测数据 | **第 4 段：问卷回收校准**（学生问卷答对率 + 5 级感受、教师目标难度匹配意见 → 标签 vs 实测混淆矩阵 → 修订规则阈值） |
| **内容/结构角度**（事前可判） | 鲍建生五因素综合难度模型（知识含量/推理/运算/思维方向/情境）；宁波 9 因素绝对难度模型（知识点数量/情境/运算/推理/认知/开放性/隐蔽性/梯度/未知参数，1~5 赋值 + 回归）；江苏省教育考试院难度分析模型（教师逐因素赋值 → 回归预测）；布鲁姆认知层次 | 先把难度拆成**可观测特征并分级**，再确定性合成 | **第 1/2/3 段：特征规格定义 + 任务卡下发 + 确定性终检** |
| **命题实践三档口径** | 容易题=基础、单一步骤、教材原情境；中等题=知识综合、多步骤、常规迁移；难题=综合探究、陌生情境、链式推理（常配 8:1:1 / 7:2:1） | 三档的操作性定义 | **档位语义的直接模板** |

## 3. 标准设计：六维特征 + 三档操作定义

### 3.1 特征维度（D1~D6）

| 维度 | 取值 | 来源 | 实现载体 |
|---|---|---|---|
| **D1 认知操作** | remember / understand / apply / analyze / evaluate / create（布鲁姆六级） | 布鲁姆；蓝图 `_DIFFICULTY_COGNITIVE_WEIGHTS` | ★已有：蓝图按难度配对分配 `cognitive_level`，合同锁定 |
| **D2 知识跨度** | 单原子 / 双原子 / 跨章多原子 | 知识含量、知识点数量、知识综合程度 | ★已有：合同槽位 `coverage_atom` 单原子锁定；规格文本声明 |
| **D3 推理步骤** | 单步 / 2~3 步 / ≥4 步链式 | 推理、运算量 | 规格文本下发；文本判定留 v2 |
| **D4 情境** | 无情境或教材原 / 常规新情境 / 陌生探究 | 情境、情境陌生程度 | 规格文本下发 |
| **D5 信息方式** | 直接给出 / 需加工转换 / 隐含条件挖掘 | 隐蔽性、信息利用方式 | 规格文本下发 |
| **D6 干扰项质量**（仅选择题） | 异质明显 / 同质近似 / 可两两混淆 | 选择题难度研究 | 规格文本下发；启发式判定留 v2 |

### 3.2 三档操作定义（`difficulty_standard.py` 权威口径）

| 档 | 认知允许集（D1，与蓝图配对表同源） | D2~D6 语义 |
|---|---|---|
| **low 容易** | remember, understand | 单原子、单步直取、教材原情境、条件直接给出、干扰项异质 |
| **medium 中等** | understand, apply, analyze | 双原子、2~3 步、常规新情境、需加工转换、干扰项同质 |
| **high 困难** | apply, analyze, evaluate, create | 跨章多原子、≥4 步链式、陌生探究、隐含条件、可两两混淆 |

词表归一：`easy→low`、`hard→high`、中文别名（容易/中等/困难…）→ 规范值，
未知值 → `medium`（与既有终检默认一致，不新增拦截面）。

## 4. 四段管线（对应"不靠 prompt 穿透"）

1. **蓝图/合同（事前，确定性）**：难度标签 + D1 认知层次本就由蓝图按配对表确定性
   分配并经合同锁定——标准的"D1"已在代码里，本设计将其显式化为允许集。
2. **任务卡（生成时，结构化字段）**：`BatchQuestionSpec.difficulty_spec` 每题携带
   完整特征规格（payload 整体 JSON 进 prompt），模型看到的是"这一档长什么样"的
   字段定义；批指令注明"终检按同一份规格做确定性校验，不是修辞建议"。
3. **终检（确定性校验，v1 两规则，仅低档）**：
   - `difficulty_mismatch`：题干含高阶认知关键词（原子术语豁免）——历史规则，现
     经词表归一后对 `easy` 同样生效；
   - `difficulty_cognitive_mismatch`：认知层次超出低档允许集（remember/understand）
     ——与蓝图配对表对齐，**可证明不误伤合法槽位**；
   - 中/高档 v1 不做文本判定（步骤数/情境的文本启发式误伤率高），只随规格下发，
     判定权问题不靠"放宽规则"解决，靠第 4 段实证校准收紧。
4. **实证校准（问卷闭环，第 4 段）**：学生问卷（作答正确率 P 值 + 5 级难度感受）与
   教师问卷（目标难度匹配五档）回收后，统计"标签 vs 实测"混淆矩阵，用于修订规则
   阈值与配对表——数据够了可升级为特征赋值 + 回归（宁波/江苏模型的路径）。

## 5. v1 实现范围

| 文件 | 改动 |
|---|---|
| `app/domain/generation/difficulty_standard.py` | **新增**：词表归一、D1 允许集、三档特征规格 `difficulty_spec`、低档终检 `check_difficulty_fit` |
| `app/services/generation_service.py` | 内联低档关键词规则替换为标准模块调用（行为兼容，词表归一补上 `easy` 缺口） |

| `tests/unit/test_difficulty_standard.py` | **新增** 13 个用例，含蓝图配对表**对齐守护测试** |

- **封存代码零改动**：`generation_graph.py` 不动——`_stamp_question` 先于
  `_check_question` 执行，槽位的 `difficulty/cognitive_level` 已盖章进题目字典，
  标准校验自然取到。
- 门禁：`uv run pytest -q` 全量 1504 passed；覆盖率 ≥80 达标。

## 6. v2 展望（明确不在 v1）

- **模型自陈字段**：output_schema 增加 `difficulty_features`（步骤数/情境类型自陈），
  作为待校验数据与规格交叉验证——需评估对 schema 校验重试面的影响后落地；
- **中/高档文本规则**：步骤链词表、情境标记的启发式判定（先在问卷数据上标定误伤率）；
- **实证回归**：问卷 P 值回流后，特征赋值 + 回归权重替代部分规则阈值（对齐江苏/
  宁波模型路径）；
- **D6 干扰项启发式**：干扰项长度同质度 / 两两混淆度。
